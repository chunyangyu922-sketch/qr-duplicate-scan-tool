二维码 / 条形码 防重复扫描工具 —— 使用说明
================================================

【功能】
  扫描发票等上面的二维码 / 条形码并保存到本地数据库。
  再次扫描到相同内容时，会弹出醒目提醒 + 声音警告，防止重复报销。
  上传发票图片 / PDF 时，会自动识别（OCR）电子发票上的购买方、销售方信息，
  包括名称和统一社会信用代码 / 纳税人识别号，一并记录、显示、导出。

【启动方法】
  双击「启动工具.bat」即可。启动后会自动打开浏览器页面。
  （需要电脑已安装 Node.js，本工具无需安装任何依赖；默认离线运行，
   若配置了科大讯飞云端识别（见下文），则仅在识别时会联网调用一次。）
  关闭弹出的黑色命令行窗口，即可停止程序。

【三种扫描方式】
  1) 摄像头扫描：点「开启摄像头」，把二维码/条形码对准镜头，识别后自动录入。
     （需用 Edge 或 Chrome 浏览器，首次会询问是否允许使用摄像头，请点允许）
  2) 上传图片 / PDF：点击虚线框选择图片或 PDF，或直接把文件拖进去，可一次多张。
     支持二维码、条形码图片，以及含二维码的 PDF（电子发票 PDF、扫描件均可，
     会自动逐页识别 PDF 中的二维码）。多个文件/图片会依次处理，不会漏扫。
     识别到发票后会自动 OCR 识别整页票面文字，自动提取购买方 / 销售方名称
     与统一社会信用代码（纳税人识别号），例如滴滴电子发票会同时保存购买方和
     销售方的名称与税号。
     一份 PDF 扫描完后，如果有个别页面没读到二维码 / 发票号码，虚线框下方会
     列出这些页码，方便核对是否漏了发票（封面、行程单、正文页属于正常情况）。
  3) 手动 / 扫码枪：把光标放到输入框，用 USB 扫码枪扫一下会自动录入；
     也可以手动输入内容后回车。

【数据保存在哪】
  数据保存在本程序目录下的 data\codes.db（SQLite 数据库文件）。
  备份方法：复制整个程序文件夹即可。删除 data\codes.db 即清空全部数据。

【常见问题】
  - 摄像头识别不出：请用 Edge / Chrome 浏览器；光线充足、对焦清晰再试。
  - 图片识别不出：换更高清、正对、不变形的图片；本工具优先识别二维码。
  - 提示“浏览器不支持”：请改用 Edge 或 Chrome 打开页面。
  - 识别购买方/销售方不准：OCR 为“尽力而为”，对歪斜、模糊、印章遮挡的票面
    可能出错。识别结果会显示在「发票信息」和「扫描记录」中，可在记录列表
    点「编辑」手动改正，或重新扫描更清晰的图片。

【发票信息 / 自动识别】
  扫描到增值税发票二维码后，会完整显示：发票类型、发票代码、发票号码、
  金额、开票日期、校验码、随机码、原始内容，并可一键前往官网查验真伪。
  上传图片/PDF 时还会自动 OCR 整页识别并显示购买方、销售方信息：
    购买方名称、购买方统一社会信用代码/纳税人识别号、
    销售方名称、销售方统一社会信用代码/纳税人识别号。

【科大讯飞云端识别（可选增强）】
  默认使用本地 Tesseract OCR（离线、免费），对清晰票面即可识别。
  如希望提升识别准确度，可申请科大讯飞增值税发票识别服务，并在本程序目录
  新建 config.json 文件（可直接复制 config.example.json 后填写），内容：
    { "xfyun": { "mode": "newapi", "appid": "…", "apikey": "…", "apisecret": "…",
                 "host": "api.xf-yun.com", "path": "/v1/private/…",
                 "serviceId": "…", "templateList": "vat_invoice" } }
  appid / apikey / apisecret / serviceId 都在讯飞控制台该服务的页面里。
  另有一套老版 WebAPI 接口（webapi.xfyun.cn）也支持，把 mode 改成 "webapi"，
  并改用 { "appid", "apikey", "url", "engineType" } 这几个字段即可。
  密钥仅保存在服务端 config.json（已被 .gitignore 排除，不会被提交），
  不会发送到浏览器。配置后，识别发票会优先走云端（更准），
  失败或无结果时自动回退本地 OCR。

【扫描记录 / 导出】
  扫描记录清晰列出：公司名称（购买方、销售方名称）、发票号、
  统一社会信用代码/纳税人识别号（购买方、销售方）、类型、首次扫描时间、
  次数，并可为每条记录添加备注，也可搜索、删除单条或全部记录。
  导出 CSV 会包含：文件名、发票号、发票代码、发票类型、金额、开票日期、
  校验码、随机码、购买方名称、购买方统一社会信用代码/纳税人识别号、
  销售方名称、销售方统一社会信用代码/纳税人识别号、扫描方式、格式、
  首次扫描、最近扫描、次数、备注、原始内容，可直接用 Excel 打开核对。
